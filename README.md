# AURIA Signature Clinic
نسخه بازطراحی‌شده نمونه‌کار سایت کلینیک زیبایی و دندانپزشکی.

اجرای محلی: npm install سپس npm run dev

امکانات: خدمات و پزشکان نمونه؛ رزرو پزشک/تاریخ/ساعت؛ بررسی تداخل رزرو؛ پنل بیمار بر اساس شماره واردشده؛ پنل مدیریت نمایشی برای تغییر وضعیت نوبت‌ها.

**هشدار:** حساب بیمار و مدیریت احراز هویت ندارند؛ داده‌ها در localStorage مرورگر نگهداری می‌شوند، بنابراین اطلاعات واقعی یا حساس وارد نکنید. تصاویر از Unsplash بارگذاری می‌شوند و نیاز به اینترنت دارند.
